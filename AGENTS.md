# Introduction
This is a development environment for integrating RTL with Chisel and SpinalHDL.
Used to develop CPUs based on the RISC-V instruction set and explore the design space.

## Directory Introduction
```text
./rtl Used to store Verilog/SystemVerilog files generated by SpinalHDL or Chisel.
./env Used to store verification environments for different tools.
./docs Used to store detailed design, verification and interface documents.
./assistant Used to store different AI agents.
./chisel Used to store chisel codes.
./spinal Used to store spinalhdl codes.
./scripts Used to store shell command scripts.
./sw Used to store software and applications.
./knowledge Used to store reference projects and documents.
```
Note that the scripts under the `scripts` directory and their naming conventions:
each script shall perform **one complete independent task only**, and the name shall start with a verb, e.g., `do_xx`, `update_xx`.

## Knowledge Directory Introduction
This folder stores reference projects necessary for design and planning.

### Requirements
You shall first refer to and understand these projects and documents, then deduce the specific implementation according to actual requirements.
